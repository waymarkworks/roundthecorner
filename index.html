Google key

The app asks Google for places, ratings, hours and the map. It needs your own Google Maps key. The key stays in this phone's browser and is never sent anywhere except Google.

How to get a key
  1. In Google Cloud, create a project and switch on billing. Personal use sits inside the free monthly allowance, but add a budget alert.
  2. Enable two APIs: Places API (New) and Maps JavaScript API.
  3. Create an API key. Restrict it to those two APIs and to this site's address (HTTP referrers).
  4. Paste it below and tap Save and test.

The app stops asking Google once it has made this many searches today on this phone. Google's own cap cannot be lowered for this API, so this is your safety net.
